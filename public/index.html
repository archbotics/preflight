Preflight documentation

Submit one public page with JSON. URLs must be HTTP(S), no more than 2,048 characters, and have no credentials, query string, IP or local hostname, or nonstandard port. Requests are GET-only; every redirect is checked again. Limits: three redirects, 512 KiB HTML, and 12 seconds total.

curl -X POST https://preflight.archbotics.workers.dev/api/check \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com","mode":"live"}'

The response includes a structured report and, when configured, a short-lived share token. Reports are stored only after POST /api/share.

A scan fetches a page to inspect its HTML and response. Raw HTML is not stored. A report is stored only when you choose Share, on Cloudflare infrastructure, for seven days. We keep daily totals for homepage openings, scans and shares, grouped by whether requests look like browsers, automated tools, or neither. These estimates do not identify individual visitors. Request headers are inspected without being stored in these totals. Usage counts respect Do Not Track and Global Privacy Control. Normal infrastructure processing may occur. The browser keeps the deletion key for reports you create; it is never part of the share link.
